# Kumarsız Android

Figma tasarımından esinlenen, internet olmadan temel özellikleri çalışabilen ilk Android sürümüdür.

## Özellikler
- Kumarsız süre sayacı
- Tahmini tasarruf hesabı (varsayılan 350 TL/gün)
- Kriz Anı ve 5 dakikalık kriz modu
- Günlük kaydı
- İstatistikler
- Hedefler, başarılar ve tetikleyiciler ekranları
- Profil ve sayacı sıfırlama
- Verilerin cihazda SharedPreferences ile tutulması

## Android Studio
1. ZIP'i aç.
2. Klasörü Android Studio ile aç.
3. Gradle senkronizasyonunu tamamla.
4. `app` > `assembleDebug` çalıştır.
5. APK: `app/build/outputs/apk/debug/app-debug.apk`

Not: Bu proje ilk çalışan MVP'dir. Yayına almadan önce gizlilik politikası, güvenli veri saklama, bildirimler ve profesyonel destek kaynakları eklenmelidir.
